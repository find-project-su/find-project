## English

A multi-module project bringing together educational materials, a visual content creation system with unified artistic guidelines, and experimental projects in artificial intelligence and emerging technologies.

### Modules

#### 📚 Educational Materials

Quick reference guides, cheat sheets, and practical instructions for development tools, AI models, and workflows.

- **EduMaterials** → [`EduMaterials/`](EduMaterials/)

#### 🎨 Visual Content System

Comprehensive guidelines and prompts for creating illustrations, icons, charts, and graphics in various artistic styles. Detailed style descriptions are available in the module.

- **ImgCreate** → [`ImgCreate/`](ImgCreate/)

#### 💼 Investment Portfolio Assistant

An AI assistant for long-term self-directed investors. It helps maintain a chosen portfolio strategy by analyzing holdings, cash flows, market context, and investment horizon, then suggesting how to allocate available funds. The investor remains in control of all decisions.

- **NoFussPortfolio** → [`NoFussPortfolio/`](NoFussPortfolio/)

### Tech Stack

- **Documentation:** MkDocs with Material theme
- **Content:** Markdown, WebP images

### Getting Started

Navigate to any module folder and read its README for detailed instructions.

## Русский

Многомодульный проект, объединяющий образовательные материалы, систему создания визуального контента с едиными художественными правилами и экспериментальные разработки в области искусственного интеллекта и современных технологий.

### Модули

#### 📚 Образовательные материалы

Справочные материалы, шпаргалки и практические инструкции для работы с инструментами разработки, ИИ-моделями и рабочими процессами.

- **EduMaterials** → [`EduMaterials/`](EduMaterials/)

#### 🎨 Система визуального контента

Подробные правила и промты для создания иллюстраций, иконок, диаграмм и графики в различных художественных стилях. Детальные описания стилей доступны в модуле.

- **ImgCreate** → [`ImgCreate/`](ImgCreate/)

#### 💼 Инвестиционный помощник

AI-помощник для самостоятельных долгосрочных инвесторов. Анализирует портфель, денежные поступления, рыночный контекст и инвестиционный горизонт, помогая распределять свободные средства в рамках выбранной стратегии. Окончательное решение остаётся за инвестором.

- **NoFussPortfolio** → [`NoFussPortfolio/`](NoFussPortfolio/)

### Технологии

- **Контент:** Markdown, изображения WebP
