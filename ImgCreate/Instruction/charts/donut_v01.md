## Универсальный промт для создания кольцевой диаграммы (бублика) в эскизном стиле

### 1. Основной запрос

Создай кольцевую диаграмму (бублик) в эскизном карандашном стиле на основе двух референсов: референса данных и референса стиля. Из референса данных извлеки все категории, их процентные значения и порядок секторов, **но только те, которые реально представлены на бублике (ненулевые значения)**. Категории, указанные в легенде референса данных, но не имеющие сектора на бублике (нулевые значения), **не переноси в итоговую диаграмму**. Из референса стиля возьми оформление: цветовую палитру, характер линий, шрифты, расположение подписей на секторах, формат легенды (кружки-маркеры), общую композицию. Итоговая диаграмма должна точно передавать данные из первого референса (только ненулевые категории), но выглядеть как аккуратный рисованный от руки график, в едином стиле со вторым референсом.

**Обязательные параметры результата:**
- Формат: альбомный, соотношение сторон 2:1 (ширина : высота = 2 : 1).
- Бублик расположен слева и занимает примерно 60% ширины композиции, легенда — справа, занимает около 40%.
- Бублик — главный элемент, его центр пустой.
- Заголовок диаграммы отсутствует.
- На секторах отображаются только процентные значения (число и знак %), без текстовых названий.
- Легенда содержит только текстовые названия категорий (без чисел), маркеры легенды — кружки.
- Все линии, контуры, подписи, текст легенды — чёрный карандаш; цвет используется только для заливки секторов.

### 2. Порядок загрузки референсных изображений

1. **Референс данных** — загружается пользователем. С него берём:
   - все категории (сектора), которые имеют ненулевые значения и реально представлены на бублике;
   - процентные значения для каждого сектора;
   - порядок секторов (по часовой стрелке, начиная с верхней точки бублика);
   - язык и формулировки названий категорий (они переносятся без изменений);
   - если на секторах есть подписи значений — их нужно заменить округлёнными целыми процентами;
   - **категории из легенды с нулевыми значениями (не имеющие сектора) игнорируются полностью**.

2. **Референс стиля** — загружается пользователем вручную. С него берём:
   - палитру цветов для секторов (если в данных меньше или больше секторов, чем в стиле, либо убирай лишние цвета, либо добавляй гармонирующие);
   - толщину и характер линий контуров секторов, внешней и внутренней окружности;
   - оформление подписей на секторах (шрифт, размер, наклон);
   - оформление легенды (структура, кружки-маркеры, шрифт);
   - общую композицию и пропорции.

### 3. Стиль и качество

Эскизный карандашный стиль, рисованный от руки. Чистый белый фон, без текстуры бумаги и посторонних элементов. Все линии, контуры, подписи, текст легенды — **чёрный карандаш** (простой графит). Цвет используется **только для заливки секторов**, в манере цветных карандашей, как на стилевом референсе: мягкая полупрозрачная заливка, не перекрывающая контуры и штриховку. Шрифт подписей и легенды должен точно соответствовать стилевому референсу (тип, начертание, размер, наклон). Запрещены печатные шрифты, компьютерная графика, элементы интерфейса.

### 4. Композиция и расположение

Формат альбомный 2:1. **Бублик располагается слева и занимает примерно 60% ширины области построения, легенда — справа, занимает около 40%.** Бублик визуально доминирует, его центр пустой (кольцо). Легенда не должна перекрываться с бубликом. Подписи на секторах — внутри секторов, проценты. Легенда содержит цветные кружки-образцы и текстовые подписи категорий. Порядок секторов и легенды согласован (по часовой стрелке, начиная с верхней точки). Отступы между бубликом и легендой достаточные, пропорции соблюдены.

### 5. Ключевые элементы и требования к данным

- **Извлечение данных:** внимательно изучи референс данных. Определи количество секторов на бублике (ненулевые категории), их процентные значения и названия. **Категории, перечисленные в легенде, но не имеющие сектора (нулевые значения), исключи из итоговой диаграммы.** Если на секторах есть подписи, используй их для извлечения значений. Если подписей нет, оцени доли визуально, максимально точно.
- **Округление значений:** если значения содержат дробную часть, округли их до целых процентов по математическим правилам. Затем проверь сумму: она должна быть ровно 100%. Если после округления сумма отличается, скорректируй одно или несколько значений (например, добавь/убери 1%) так, чтобы итог был 100%. Отображай на секторах только целые проценты со знаком «%».
- **Точное соблюдение пропорций секторов:** перед отрисовкой вычисли угол каждого сектора по формуле: **угол = процентное значение × 3.6°**. Сектор с 50% должен занимать ровно половину окружности бублика, 25% — четверть и т.д. Строго следуй этим вычислениям при построении секторов, не допускай визуальных искажений. Проверь, чтобы сумма углов равнялась 360°. Если на референсе данных имеются визуальные искажения, исправь их в итоговой диаграмме.
- **Названия категорий:** перенеси названия из референса данных без изменений (язык, формулировки), но только для категорий с ненулевыми значениями. Если легенда на референсе данных уже есть, возьми названия из неё, но отбрось пункты с нулевыми значениями. Если названий нет, найди их рядом с секторами или под диаграммой.
- **Легенда:** список пунктов по количеству ненулевых секторов. Каждый пункт: цветной кружок-образец (цвет сектора) + текстовая подпись категории. **Без числовых значений в легенде.**
- **Отображение значений на секторах:** только проценты (число + знак %). Число и знак процента располагаются внутри секторов, читаемо. Шрифт — по стилевому референсу.
- **Цвета секторов:** используй палитру стилевого референса. Если количество секторов в данных отличается от эталона, либо убери лишние цвета, либо добавь новые, гармонирующие с существующими. Цвета должны быть различимы, пастельные, в манере цветных карандашей.
- **Линии:** контуры секторов — чёрный карандаш, тонкие, ровные, от руки. Внешняя и внутренняя окружности — чёрные карандашные линии.
- **Фон:** чистый белый, без текстуры.
- **Заголовок:** отсутствует полностью.

### 6. Настроение и посыл

Диаграмма должна выглядеть как аккуратный рисованный от руки график для презентации, передающий точность данных и тепло ручной работы. Бублик — главный визуальный акцент, легенда дополняет, но не конкурирует с ним. Визуально приятная, читаемая, без лишних деталей.

### 7. Технические параметры

- **Формат:** альбомный, соотношение сторон 2:1 (ширина : высота = 2 : 1).
- **Пропорции:** бублик занимает около 60% ширины, легенда — 40%.
- **Фон:** чистый белый, без текстуры.
- **Текст:** на бублике — только проценты (число + знак %); в легенде — только текстовые названия категорий (без чисел и знаков %). Язык текста сохраняется из референса данных. Шрифт — строго по стилевому референсу (тип, размер, начертание).
- **Линии:** чёрные карандашные, от руки, с лёгкой рукотворной неровностью.
- **Цвет:** только заливка секторов в цвете, согласно палитре стилевого референса. Всё остальное — ч/б.
- **Маркер легенды:** цветной кружок.
- **Качество:** высокая детализация, но без перегруженности; все элементы хорошо читаются в заданном формате.
