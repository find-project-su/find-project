## Универсальный промт для создания гистограммы в эскизном стиле

### 1. Основной запрос

Создай вертикальную гистограмму в эскизном карандашном стиле на основе двух референсов: референса данных и референса стиля. Из референса данных извлеки все категории, их числовые значения и порядок столбцов, **но только те, которые реально представлены на гистограмме (ненулевые значения)**. Категории, указанные в легенде референса данных, но не имеющие столбца на графике (нулевые значения), **не переноси в итоговую диаграмму**. Из референса стиля возьми оформление: шрифт, компоновку, расположение легенды, стиль осей, штрихов, подписей, форму маркеров легенды, характер линий и заливки. Итоговая диаграмма должна точно передавать данные из первого референса (только ненулевые категории), но выглядеть как аккуратный рисованный от руки график, в едином стиле со вторым референсом.

**Обязательные параметры результата:**
- Формат: альбомный, соотношение сторон 2:1 (ширина : высота = 2 : 1).
- Гистограмма расположена справа, легенда — слева, внутри тонкой рамки, с квадратными маркерами.
- Заголовок диаграммы отсутствует.
- Под осью X подписей категорий нет (категории только в легенде).
- Над каждым столбцом — подпись значения в процентах (число и знак %), без текстовых названий.
- Легенда содержит только текстовые названия категорий (без числовых значений).
- Все линии, контуры, подписи, текст легенды — чёрный карандаш; цвет используется только для заливки столбцов и маркеров легенды.
- Высота столбцов строго пропорциональна значениям, начиная от нулевой линии.

### 2. Порядок загрузки референсных изображений

1. **Референс данных** — загружается пользователем. С него берём:
   - все категории (столбцы), которые имеют ненулевые значения и реально представлены на гистограмме;
   - числовые значения для каждого столбца (в процентах или абсолютных числах, как указано);
   - порядок столбцов (слева направо);
   - язык и формулировки названий категорий (они переносятся без изменений);
   - если на столбцах есть подписи значений — их нужно заменить округлёнными целыми процентами;
   - **категории из легенды с нулевыми значениями (не имеющие столбца) игнорируются полностью**.

2. **Референс стиля** — загружается пользователем вручную. С него берём:
   - шрифт подписей (тип, размер, начертание, характер);
   - компоновку (расположение области построения, легенды, отступы);
   - оформление легенды (рамка, квадратные маркеры, порядок строк);
   - стиль осей и штрихов (толщина, длина, наличие);
   - стиль заливки столбцов (цветные карандаши, полупрозрачность, фактура);
   - палитру цветов (если в данных меньше или больше столбцов, чем в стиле, либо убирай лишние цвета, либо добавляй гармонирующие);
   - общий вид и баланс элементов.

### 3. Стиль и качество

Эскизный карандашный стиль, рисованный от руки. Чистый белый фон, без текстуры бумаги и посторонних элементов. Все линии, контуры, оси, подписи, текст легенды — **чёрный карандаш** (простой графит). Цвет используется **только для заливки столбцов и маркеров легенды**, в манере цветных карандашей, как на референсе стиля: мягкая полупрозрачная заливка, не перекрывающая контуры и штриховку. Шрифт подписей и легенды должен точно соответствовать референсу стиля (тип, начертание, размер, наклон). **Не придумывай оформление — строго следуй референсу стиля.** Запрещены печатные шрифты, компьютерная графика, элементы интерфейса.

### 4. Композиция и расположение

Формат альбомный 2:1. **Область построения гистограммы (оси, столбцы, подписи значений) расположена справа и занимает основную часть кадра.** **Легенда находится слева, внутри тонкой рамки, и не перекрывает столбцы, оси и подписи значений.** Легенда компактная, с квадратными маркерами, читаемая.

- Ось X (горизонтальная) — тонкая чёрная линия с короткими штрихами вверх (для обозначения позиций столбцов), но **без подписей категорий под осью**.
- Ось Y (вертикальная) — тонкая чёрная линия со штрихами вправо, **без числовых подписей**.
- Столбцы располагаются равномерно вдоль оси X, имеют одинаковую ширину, высота пропорциональна значению.
- Подписи значений — над каждым столбцом: число + знак процента, рукописным шрифтом (стиль — с референса).
- Заголовок отсутствует полностью.

### 5. Ключевые элементы и требования к данным

- **Извлечение данных:** внимательно изучи референс данных. Определи количество столбцов (ненулевые категории), их значения и названия. **Категории, перечисленные в легенде, но не имеющие столбца (нулевые значения), исключи из итоговой диаграммы.** Если на столбцах есть подписи, используй их для извлечения значений. Если подписей нет, оцени высоты визуально, максимально точно.
- **Округление значений:** если значения содержат дробную часть, округли их до целых чисел по математическим правилам. Отображай на столбцах только целые значения со знаком «%».
- **Точное соблюдение пропорций высоты:** высота каждого столбца должна строго соответствовать его значению относительно нулевой линии (ось Y начинается от 0). Разница высот между столбцами должна точно отражать разницу значений: например, столбец 50% должен быть в два раза выше столбца 25%. Проверяй пропорции при отрисовке, не допускай визуальных искажений.
- **Названия категорий:** перенеси названия из референса данных без изменений (язык, формулировки), но только для категорий с ненулевыми значениями. Если легенда на референсе данных уже есть, возьми названия из неё, но отбрось пункты с нулевыми значениями.
- **Легенда:** список пунктов по количеству ненулевых столбцов. Каждый пункт: квадратный маркер цвета столбца + текстовая подпись категории. **Без числовых значений в легенде.**
- **Подписи значений:** только проценты (число + знак %). Располагаются над каждым столбцом, читаемо, не перекрываются.
- **Цвета столбцов:** используй палитру референса стиля. Каждый столбец должен иметь уникальный, легко различимый цвет. Если количество столбцов в данных отличается от эталона, либо убери лишние цвета, либо добавь новые, гармонирующие с существующими. Цвета должны быть пастельные, в манере цветных карандашей. **Соседние столбцы не должны сливаться.**
- **Оси:** горизонтальная (X) и вертикальная (Y) — тонкие чёрные карандашные линии со штрихами делений, как на референсе стиля. Без сетки, без подписей осей.
- **Фон:** чистый белый, без текстуры.
- **Заголовок:** отсутствует.

### 6. Настроение и посыл

Гистограмма должна выглядеть как аккуратный рисованный от руки график для презентации, передающий точность данных и тепло ручной работы. Легенда дополняет, но не конкурирует с графиком. Визуально приятная, читаемая, без лишних деталей.

### 7. Технические параметры

- **Формат:** альбомный, соотношение сторон 2:1 (ширина : высота = 2 : 1).
- **Фон:** чистый белый, без текстуры.
- **Текст:** подписи значений — только проценты (число + знак %); легенда — только текстовые названия категорий (без чисел и знаков %). Язык текста сохраняется из референса данных. Шрифт — строго по референсу стиля (тип, размер, начертание).
- **Линии:** чёрные карандашные, от руки, с лёгкой рукотворной неровностью.
- **Цвет:** только заливка столбцов и маркеры легенды, согласно палитре референса стиля. Всё остальное — ч/б.
- **Маркер легенды:** квадратик соответствующего цвета.
- **Качество:** высокая детализация, но без перегруженности; все элементы хорошо читаются в заданном формате.
