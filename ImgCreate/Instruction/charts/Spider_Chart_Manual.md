# English

## Spider Chart Workflow

1. Open `Spider 0-10scale_Examples.xlsx`.
2. Select the sheet with the required number of axes (5 or 6).
3. Replace categories and values with your own.
4. Take a screenshot of the chart.
5. Choose the corresponding universal prompt:
   - `5axis_Spider 0-10scale Template_v01.md` for 5 axes;
   - `6axis_Spider 0-10scale Template_v01.md` for 6 axes.
6. Insert your data into the prompt table.
7. Upload the screenshot as the only reference and run generation.

# Русский

## Инструкция по работе с диаграммами-паутинками

1. Откройте файл `Spider 0-10scale_Examples.xlsx`.
2. Выберите лист с нужным количеством осей (5 или 6).
3. Замените категории и значения на свои.
4. Сделайте скриншот диаграммы.
5. Выберите соответствующий универсальный промт:
   - `5axis_Spider 0-10scale Template_v01.md` для 5 осей;
   - `6axis_Spider 0-10scale Template_v01.md` для 6 осей.
6. Вставьте свои данные в таблицу промта.
7. Загрузите скриншот эскиза как единственный референс и выполните генерацию.
