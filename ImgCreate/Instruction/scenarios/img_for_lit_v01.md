# Инструкция по созданию серии иллюстраций к литературному произведению (v1.0)

## 1. Общие положения

Данная инструкция описывает алгоритм создания серии иллюстраций к литературному произведению любого жанра: рассказ, повесть, поэма, роман, стихотворение. Серия создаётся в единой стилистике и следует общему процессу: уточнение задачи → определение параметров → разбор текста → создание каждой иллюстрации → формирование итогового файла.

**Результат работы:** Markdown-файл с текстом произведения, в который в нужных местах вставлены иллюстрации. Файл передаётся в макет для дальнейшей вёрстки.

## 2. Ключевые параметры серии

Перед началом работы необходимо определить и зафиксировать:

1. **Произведение** — текст, к которому создаётся серия.
2. **Формат иллюстраций** — соотношение сторон и ориентация (см. раздел 4).
3. **Плотность иллюстрирования** — количество иллюстраций на объём текста (см. раздел 3).
4. **Стиль** — по умолчанию ч/б карандашный скетч на белом фоне; отклонения только по явному указанию.
5. **Главный персонаж** — используется ли существующий или создаётся новый образ.
6. **Назначение** — мини-книжка, публикация, обучающий материал, презентация.

Параметры фиксируются до начала разбора текста. Изменение параметров в процессе возможно, но требует пересмотра уже созданных иллюстраций.

## 3. Плотность иллюстрирования

**Базовое правило:** одна иллюстрация на каждые **1500–2000 символов** текста.

Это соответствует примерно:
- 250–350 слов;
- 1–1,5 страницы стандартного книжного текста;
- одной крупной сцене или двум–трём коротким эпизодам.

**Расчёт количества иллюстраций:**
1. Определить объём текста в символах (с пробелами).
2. Разделить на 1750 (среднее значение диапазона).
3. Округлить до целого.
4. Скорректировать по смыслу: если в тексте есть яркие сцены, требующие визуализации, количество можно увеличить; если текст однородный — уменьшить.

**Пример:** рассказ объёмом 7000 символов → 7000 / 1750 = 4 иллюстрации.

**Ограничения:**
- Минимум — 2 иллюстрации (одна в начале, одна в финале).
- Максимум — 12–15 иллюстраций на произведение (дальше теряется эффект акцента).
- Для стихотворений и коротких поэм правило может не применяться: иллюстрация создаётся к каждой смысловой строфе или к ключевому образу.

## 4. Формат и ориентация

Формат определяется в начале работы и остаётся единым для всей серии. Соотношение сторон задаётся пользователем или выбирается по умолчанию в зависимости от типа произведения.

### Рекомендуемые форматы

| Тип произведения | Формат | Соотношение | Ориентация | Примечание |
|------------------|--------|-------------|------------|------------|
| Короткий рассказ | A6 | 105:148 | книжная | Иллюстрация на всю страницу |
| Рассказ, повесть | A5 | 148:210 | книжная | Иллюстрация на всю страницу |
| Повесть, роман | A5 / A4 | 148:210 / 210:297 | книжная | Возможны полосные и полуполосные |
| Стихотворение | A6 | 105:148 | книжная | Иллюстрация к строфе |
| Презентация / слайды | 16:9 | 1920:1080 | альбомная | Иллюстрация как слайд |
| Соцсети / анонс | 1:1 | 1080:1080 | квадрат | Иллюстрация как карточка |

### Правила формата

- **Единый формат для всей серии.** Все иллюстрации имеют одинаковое соотношение сторон и ориентацию.
- **Полностраничная иллюстрация.** Для книжных форматов иллюстрация занимает всю страницу, с полями, соответствующими вёрстке.
- **Квадрат как универсальный.** Если формат не задан, по умолчанию используется 1:1.
- **Отклонения** от единого формата возможны только по явному указанию (например, одна иллюстрация — разворот).

## 5. Алгоритм работы над серией

### Шаг 1. Уточнение задачи
- Определить произведение и его объём.
- Зафиксировать формат, ориентацию, плотность.
- Определить назначение (книжка, публикация, обучающий материал).
- Уточнить, используется ли готовый персонаж или создаётся новый.

### Шаг 2. Разбор текста
- Разделить текст на смысловые блоки (сцены, эпизоды, строфы).
- Определить ключевые моменты: завязка, поворотные точки, кульминация, финал.
- Выбрать сцены для иллюстрирования согласно плотности.
- Составить список иллюстраций с краткими названиями.

### Шаг 3. Согласование списка
- Предложить пользователю список сцен.
- Утвердить или скорректировать.
- Зафиксировать порядок иллюстраций.

### Шаг 4. Создание каждой иллюстрации
Для каждой сцены:
1. **Идея** — смысл, метафора, ключевые элементы.
2. **Концепция** — образ персонажа, композиция, детали, настроение.
3. **Утверждение** концепции пользователем (обязательно).
4. **Промт** в формате Markdown с указанием референсов.

### Шаг 5. Определение эталонной иллюстрации
- После генерации первых иллюстраций определить **самую удачную**.
- Утвердить её как **эталон серии**.
- Использовать как дополнительный референс для всех последующих иллюстраций (см. раздел 6).

### Шаг 6. Формирование итогового Markdown-файла
- Вставить иллюстрации в текст согласно разметке (см. раздел 7).
- Проверить единообразие стиля, формата, персонажей.
- Передать файл в макет для дальнейшей вёрстки.

## 6. Принцип целостности серии

**Ключевое правило:** когда создана первая удачная иллюстрация, она используется как дополнительный референс для всех последующих иллюстраций этой серии.

### Что это даёт
- Единообразие образа персонажа: одежда, причёска, силуэт, манера штриховки.
- Единая стилистика серии: модель «видит» утверждённый скетч и подстраивается под него.
- Снижение риска «разъезда» деталей между сценами.
- Экономия формулировок в промтах.

### Порядок работы с эталоном
1. Первая иллюстрация создаётся по базовым референсам (лицо, фигура, поза).
2. Если результат удачен — она утверждается как эталон серии.
3. Для каждой следующей иллюстрации эталон добавляется референсом с пометкой: «референс для целостности образа и стиля серии».
4. Если в какой-то сцене внешность должна измениться (например, платье становится опрятнее в финале), это явно оговаривается в промте.

### Порядок загрузки референсов
1. Крупный план лица персонажа (обязательно).
2. Полный рост персонажа (обязательно).
3. Эталонная иллюстрация серии (если создана).
4. Референсы специфических элементов (логотипы, предметы, позы) — по необходимости.

## 7. Разметка иллюстраций в итоговом файле

### Принципы размещения
- Иллюстрация ставится **после разрешения сцены** — читатель сначала переживает момент, затем видит его зафиксированным.
- Альтернатива: **на пике напряжения**, если сцена короткая и динамичная.
- Иллюстрации работают как **визуальные паузы**, не разрывая повествование.
- Не ставить иллюстрацию в середине абзаца или на стыке реплик диалога.

### Формат разметки
- Иллюстрация обозначается как отдельный блок с указанием имени файла:
![](filename.jpg)

- **Ориентир, а не жёсткая позиция.** Указанное место — рекомендуемое. При вёрстке возможен небольшой сдвиг (на абзац выше или ниже), если это нужно для красоты разворота, устранения висячих строк или баланса страницы.
- Подписи к иллюстрациям не добавляются.
- Имена файлов иллюстраций — единообразные, с порядковым номером (например, `001_illustration.jpg`, `002_illustration.jpg`).
- Итоговый файл сохраняется в Markdown и передаётся в макет для дальнейшей вёрстки.

## 8. Типичные ошибки

- **Слишком много иллюстраций.** Превышение плотности размывает эффект акцента.
- **Разный формат у иллюстраций одной серии.** Все иллюстрации должны быть в едином формате.
- **Игнорирование эталона.** Если первая удачная иллюстрация не используется как референс, серия «разъезжается».
- **Размещение иллюстрации в середине сцены.** Иллюстрация работает как пауза после разрешения.
- **Перегрузка деталями.** В одной иллюстрации не должно быть больше 5–7 смысловых элементов. Воздух и пространство важнее плотности.
- **Отсутствие утверждения концепции.** Промт не пишется без утверждения концепции пользователем.
- **Забытые референсы.** Для каждой иллюстрации с персонажем обязательны референсы лица и фигуры.

## 9. Формат

- Все промты оформляются в Markdown.
- Промты следуют структуре, принятой в проекте.
- Для серии к литературному произведению базовый процесс: идея → концепция → утверждение → промт.
- Отклонения от базового стиля (тёмный фон, цвет, иные форматы) — только по явному указанию.
- **Итоговый результат** — Markdown-файл с текстом произведения и вставленными иллюстрациями, готовый к передаче в макет.
