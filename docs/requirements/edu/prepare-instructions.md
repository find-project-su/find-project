# REQ-005: Подготовить инструкции по Docs as Code

!!! info "Статус: В разработке 🚧"
    **Связанная задача:** [#10 - EduMaterials setup](https://github.com/find-project-su/find-project/issues/10)  
    **Веха:** Educational Materials 2026

## 📖 Описание

Создание полного комплекта обучающих материалов по подходу "Документация как код" в экосистеме GitHub. Материалы должны позволить любому участнику проекта настроить и использовать систему документации без обращения к внешним источникам.

## 🎯 Цель

Обновить модуль `EduMaterials/` актуальными инструкциями по новому подходу работы с документацией. Заменить устаревшие материалы (основанные на Jira + Confluence) на современные инструкции по MkDocs и GitHub.

## 📋 Что нужно подготовить
