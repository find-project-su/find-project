# REQ-006: Документировать стили кольцевых диаграмм (бубликов)

!!! info "Статус: В разработке 🚧"
    **Связанная задача:** [#12 - Документировать стили кольцевых диаграмм](https://github.com/find-project-su/find-project/issues/12)  
    **Веха:** Chart Styles

## 📖 Описание

Систематизировать наработанные стили кольцевых диаграмм (бубликов) как переиспользуемые референсы. Цель — ускорить подготовку презентаций и обеспечить визуальное разнообразие без потери качества.

## 🎯 Цель

Создать библиотеку универсальных промтов для генерации диаграмм-бубликов в разных художественных стилях, чтобы любой участник проекта мог быстро выбрать подходящий стиль и получить предсказуемый результат.

## 📊 Стили для документирования

| Стиль | Краткое описание | Где применяется |
|-------|------------------|-----------------|
| 🖊️ Карандашный | Чёрно-белый набросок от руки, штриховка | Базовый стиль проекта |
| ✏️ Меловой | Имитация рисунка мелом на доске, тёмный фон | Образовательные материалы, ретро-стиль |
| 💡 Неоновый | Яркие светящиеся линии на тёмном фоне | Tech-презентации, IT-темы |
| 🖍️ Фломастерный | Насыщенные цвета, жирные контуры | Детская аудитория, неформальные слайды |
| 🎨 Акварельный | Мягкие переходы цвета, размытые края | Маркетинг, креативные презентации |
| 📐 Изометрический | 3D-вид под углом, технические детали | Технические презентации, архитектура |

## 📁 Структура промтов в репозитории

Все промты хранятся в модуле `ImgCreate/Instruction/charts/`. Для каждого стиля должен быть создан отдельный `.md` файл:

```
ImgCreate/Instruction/charts/
├── donut_v01.md                    ← Базовый карандашный стиль
├── donut_chalk_v01.md              ← Меловой стиль (Темная тема)
├── donut_neon_v01.md               ← Неоновый стиль (Темная тема)
├── donut_marker_v01.md             ← Фломастерный стиль
├── donut_watercolor_v01.md         ← Акварельный стиль
└── donut_isometric_v01.md          ← Изометрический стиль
```

## 🖼️ Эталонные примеры

Эталонные картинки стилей публикуются **вне этого репозитория** — в датасете **LS_ImgCreate** на Hugging Face:

👉 [Hugging Face Dataset: LeonidSmoliuk/LS_ImgCreate](https://huggingface.co/datasets/LeonidSmoliuk/LS_ImgCreate)

Полный путь к эталонам внутри датасета: `https://huggingface.co/datasets/LeonidSmoliuk/LS_ImgCreate/tree/main/Reference_Imgs`

Формат эталонных изображений:
- **Размер:** 2048×1024 px (альбомная ориентация 2:1)
- **Формат файла:** WebP (качество 75%)
- **Именование:** `<номер>_<стиль>_<версия>.webp` (например, `20006_donut_watercolor-style_base_v01.webp`)

## 📋 Что должно быть в каждом файле стиля

- [ ] Название стиля и краткое описание
- [ ] Полный промт для генерации бублика

## ✅ Критерии приемки

- [ ] Все 6 стилей задокументированы в отдельных `.md` файлах в `ImgCreate/Instruction/charts/`
- [ ] Каждый файл содержит рабочий промт, протестированный на 3+ разных наборах данных
- [ ] Для каждого стиля есть эталонная картинка (2048×1024, WebP) в датасете LS_ImgCreate
- [ ] Обновлён `ImgCreate/README.md` — добавлена секция со стилями бубликов
