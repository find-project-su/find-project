## 🎨 Общее описание
Все иллюстрации проекта должны быть выполнены в едином стиле "карандашного наброска" с соблюдением пропорций и теней.

## 📐 Основные правила
1. **Толщина линий:** Основная линия контура — 2-3px, вспомогательные штрихи — 1px.
2. **Штриховка:** Использовать перекрестную штриховку для теней.
3. **Отступы:** Иконки должны иметь поле (padding) не менее 10% от размера холста.

## ✅ Критерии приемки
- [ ] Создан эталонный образец (эталон) стиля
- [ ] Согласованы цветовые ограничения (ч/б)
- [ ] Проверена читаемость в малом размере (16x16 px)
